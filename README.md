Tank Volume Calculator

A Python program for calculating the volume of different tank geometries.

Features:
Calculates the volume of cylindrical tanks
Calculates the volume of spherical tanks
Calculates the volume of conical tanks
Accepts user inputs for dimensions
Displays results in cubic metres
Technologies
Python
Math library
How to Run

Run main.py using Python.

The program asks the user to select a tank shape and enter the required dimensions before calculating the volume.

Engineering Concepts

The program applies standard geometric volume equations to calculate the capacity of common tank shapes.
